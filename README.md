# teamwipers-civictrack

PROBLEM STATEMENT

Civic issues such as potholes, overflowing garbage bins, broken streetlights, leaking pipelines, and damaged public property are common in every city. Citizens often notice these issues before municipal authorities do, but there is usually no easy, transparent way to report them.

Even when a complaint is made — over a phone call, at a ward office, or through scattered social media posts — it frequently disappears into an untracked system. The citizen has no visibility into whether the complaint was received, assigned to a department, actioned, or resolved. This creates several problems: repeated, unresolved civic issues that erode citizen trust in local governance; duplicate complaints for the same issue since there is no shared visibility; no accountability trail for the municipal departments handling the issue; and wasted staff time manually collating complaints from calls, letters, and social media.

There is no simple, transparent, end-to-end platform that lets citizens report civic issues with photo evidence and location, and then lets both the citizen and the municipal body track that report through to resolution. Closing this loop — from report, to acknowledgment, to action, to resolution — is the core problem this project addresses.
